## Featured Projects

### CineMatch AI — Movie Recommendation System

A content-based recommendation system that identifies movies similar to a user's selection using textual features and similarity scoring.

- TF-IDF vectorization and cosine similarity
- MovieLens dataset and TMDB API integration
- Movie recommendations with poster and metadata display
- Streamlit-based user interface

### Plant Disease Detection

A deep learning application that classifies plant leaf images into healthy or disease-specific categories.

- MobileNetV2 transfer learning
- TensorFlow-based image classification
- 16-class PlantVillage dataset
- Streamlit interface and FastAPI prediction endpoint

### SmartHire AI — Resume Screening

An AI-assisted resume screening project designed to compare candidate resumes against job descriptions.

- Text extraction and preprocessing
- TF-IDF-based text representation
- Cosine similarity for relevance scoring
- Candidate ranking based on resume-job description similarity
